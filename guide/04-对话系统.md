## 4.2 SSE 流式对话

### 4.2.1 后端实现

```typescript
// chat.controller.ts
@Post('sse')
@Sse()
async chatSse(@Body() dto: ChatSseDto) {
  return this.chatService.chatStream(dto);
}
```

```typescript
// chat.service.ts
async *chatStream(dto: ChatSseDto) {
  const chatId = dto.chatId || this.createSessionId();

  // 会话级取消机制
  const controller = new AbortController();
  ChatStreamRegistry.register(chatId, controller);

  // 延迟持久化用户消息
  const userMessageId = await this.messageService.saveUserMessage({
    chatId, content: dto.message,
  });

  // 联网搜索（可选）
  let searchContext = '';
  if (dto.webSearch) {
    const organic = await this.serperService.search(dto.message);
    searchContext = this.serperService.formatSearchContextForPrompt(organic);
    yield { type: 'searchOrganic', data: organic };
  }

  // 构建消息历史
  const messages = await this.buildMessages(chatId, searchContext);

  // LLM 流式调用
  const llm = createLlm({ preset: 'chat' });
  const stream = await llm.stream(messages, { signal: controller.signal });

  // 流式输出
  for await (const chunk of stream) {
    if (chunk.signal === 'thinking') {
      yield { type: 'thinking', data: chunk.content };
    } else {
      yield { type: 'delta', data: chunk.content };
    }
  }

  // 完成后保存
  const assistantContent = stream.getFullContent();
  yield { type: 'done', data: { content: assistantContent, citations: [] } };

  // 异步落库
  await this.messageService.saveAssistantMessage({
    chatId, content: assistantContent,
  });

  ChatStreamRegistry.unregister(chatId);
}
```

### 4.2.2 SSE 事件协议

| type | 说明 | payload |
|------|------|---------|
| `thinking` | 思考链内容 | `{ content: string }` |
| `delta` | 正文 token | `{ content: string }` |
| `searchOrganic` | 联网搜索结果 | `{ organic: OrganicResult[] }` |
| `done` | 流式结束 | `{ content: string, citations: Citation[] }` |
| `error` | 错误 | `{ message: string }` |

### 4.2.3 前端 SSE 客户端

```typescript
// utils/sse.ts
export async function* streamFetch(url: string, options?: RequestInit) {
  const response = await fetch(url, {
    ...options,
    headers: {
      'Content-Type': 'application/json',
      Accept: 'text/event-stream',
      ...options?.headers,
    },
  });

  if (!response.ok || !response.body) {
    throw new Error(`HTTP ${response.status}`);
  }

  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let buffer = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    buffer += decoder.decode(value, { stream: true });
    const lines = buffer.split('\n');
    buffer = lines.pop() || '';

    for (const line of lines) {
      if (!line.startsWith('data:')) continue;
      const json = line.slice(5).trim();
      if (json === '[DONE]') { yield { done: true }; return; }

      try {
        const event = JSON.parse(json);
        if (event.type === 'thinking') yield { type: 'thinking', data: event.data };
        else if (event.type === 'searchOrganic') yield { type: 'searchOrganic', data: event.data };
        else if (event.type === 'delta') yield { type: 'data', data: event.data };
        else if (event.type === 'done') yield { done: true, data: event.data };
        else if (event.type === 'error') throw new Error(event.data?.message);
      } catch { /* 忽略非 JSON 行 */ }
    }
  }
}
```

### 4.3.1 消息树结构

```typescript
// chat.entity.ts
@Entity()
export class Message {
  @PrimaryGeneratedUUID()
  id: string;

  @Column()
  chatId: string;

  @Column('text')
  content: string;

  @Column('json', { nullable: true })
  parentId?: string;        // 父消息 ID
  childrenIds?: string[];   // 子分支 ID 列表

  @Column({ type: 'enum', enum: ['user', 'assistant', 'system'] })
  role: 'user' | 'assistant' | 'system';
}
```

### 4.3.2 分支渲染

```typescript
// ChatBotView.tsx
function buildMessageList(
  flatMessages: Message[],
  selectedChildMap: Map<string, string>,
): Message[] {
  const messageMap = new Map(flatMessages.map(m => [m.id, m]));
  const roots = flatMessages.filter(m => !m.parentId);

  function collectBranch(message: Message): Message[] {
    const selectedChildId = selectedChildMap.get(message.id);
    const children = message.childrenIds || [];

    // 找到当前选中的分支
    let targetChildId = selectedChildId || children[children.length - 1];
    const child = targetChildId ? messageMap.get(targetChildId) : null;

    if (child) {
      return [message, ...collectBranch(child)];
    }
    return [message];
  }

  return roots.flatMap(collectBranch);
}
```

```typescript
async stopSse(chatId: string) {
  const controller = ChatStreamRegistry.get(chatId);
  if (controller) {

    // Redis 缓存标记
    await redis.set(`chat:cancel:${chatId}`, '1', 'EX', 300);

}
```

## 4.5 联网搜索（Serper）

### 4.5.1 后端实现

```typescript
// serper.service.ts
@Injectable()
export class SerperService {
  async search(query: string): Promise<OrganicResult[]> {
    const res = await fetch('https://google.serper.dev/search', {
      method: 'POST',
      headers: {
        'X-API-KEY': this.configService.get('SERPER_API_KEY'),
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({ q: query, gl: 'cn', num: 10 }),
    });

    if (!res.ok) throw new Error('Serper search failed');
    const data = await res.json();
    return data.organic || [];
  }

  formatSearchContextForPrompt(results: OrganicResult[]): string {
    return results.map((r, i) =>
      `[${i + 1}] ${r.title}\n${r.snippet}\nURL: ${r.link}`
    ).join('\n\n');
  }
}
```

### 4.5.2 引用锚点处理

```typescript
// chat.service.ts
applyOrganicCitationAnchors(content: string, organic: OrganicResult[]): string {
  // 将模型输出的【n】、[n] 转为 data-organic-cite 锚点
  return content.replace(
    /【(\d+)】|\[(\d+)\]/g,
    (match, p1, p2) => {
      const idx = parseInt(p1 || p2);
      const result = organic[idx - 1];
      if (!result) return match;
      return `<a href="${result.link}" data-organic-cite="${idx}" target="_blank" rel="noopener noreferrer">${match}</a>`;
    },
  );
}
```

```typescript
buildAttachmentMessage(attachments: Attachment[]): Message[] {
  const ocrPromises = attachments
    .filter(a => isImageMime(a.mime))
    .map(async a => {
      const ocrService = this.ocrService || createLlm({ preset: 'ocr' });
```

## 4.7 BullMQ 异步落库

### 4.7.1 消息队列

```typescript
// chat-message.processor.ts
@Processor({ name: 'chat-message-queue' })
export class ChatMessageProcessor {
  @Process('save-message')
  async saveMessage(job: { data: SaveMessageJob }) {
    const { chatId, messages } = job.data;

    // 同 chatId 内存锁串行写入
    const lockKey = `chat:lock:${chatId}`;
    if (this.activeLocks.has(lockKey)) {
      // 排队等待
      await this.waitForLock(lockKey);
    }

    this.activeLocks.add(lockKey);
    try {
      for (const msg of messages) {
        await this.messageService.saveMessage(msg);
      }
    } finally {
      this.activeLocks.delete(lockKey);
    }
  }
}
```

## 4.9 消息发送按钮封装（MessageSendButton / MessageSendControl）

> 详细实现对照见 [docs/chat/消息发送按钮封装.md](../docs/chat/消息发送按钮封装.md)。

### 4.9.1 抽取动机

抽取前，发送/停止按钮的视觉与交互**散落**在两处且互相漂移：

| 接入方 | 旧实现 | 问题 |
|--------|--------|------|
| `components/design/ChatEntry/index.tsx` | 内联 ~150 行三态 JSX（停止钮 + Tauri 语音菜单 + 纯发送钮） | `inputModeMenuOpen` 状态机耦合在 ChatEntry 主体，行数膨胀、菜单逻辑无法独立测试 |
| `views/knowledge/KnowledgeAssistantEntry.tsx` | 重复实现停止钮 + 发送钮 | 样式常量与 ChatEntry 不同（`bg-teal-500/20` vs `from-teal-300/80`），图标/loading 态难以统一 |

### 4.9.2 组件分层

```
MessageSendButton/                # apps/frontend/src/components/design/
├── MessageSendButton.tsx         # 视觉底座（无业务状态）
├── MessageSendControl.tsx        # 三态状态机外壳
└── index.ts                      # barrel 导出
```

| 组件 | 职责 | 关键点 |
|------|------|--------|
| `MessageSendButton` | 发送钮视觉底座 | `MESSAGE_SEND_BUTTON_CLASS` 统一浅底渐变（teal 10%）+ ring；`forwardRef` 透传；`children ?? loadingIcon ?? icon` 三级图标回退 |
| `MessageSendControl` | 三态分发 | `loading && onStop` → 停止钮；`voiceMenu` → 语音菜单；否则纯发送钮 |
| `VoiceMenuSendButton` | Tauri 语音菜单 | 自带 `menuOpen`/`closeTimerRef` 状态机；悬停展开、220ms 延时关、点击发送并关菜单 |
| `MessageStopButton` | 停止生成钮 | `rose-500` 警示色 + 呼吸动画 |
| `VoicePrimaryIcon` | 语音主钮图标 | 四态分发：有正文 Rocket / 非语音 Rocket / 转写 Loader2 / 录音 Square / 空闲 Mic |

### 4.9.3 接入方式

```tsx

  onStop={stopGenerating}

  sendLoading={loading}   // loading 但无 onStop：发送钮转 spinner 而非变停止钮
```

### 4.9.4 关键决策

1. **视觉底座与状态机分离**：接入方只声明状态（`loading` / `onStop` / `voiceMenu`），不关心 JSX 结构，便于第三处接入（如英语 Agent）零成本复用。
2. **样式常量统一出口**：`MESSAGE_SEND_BUTTON_CLASS` 比旧版实底（80%）更轻（10% 渐变 + ring），暗色主题下不刺眼、更贴合卡片背景；停止钮 `STOP_BUTTON_CLASS` 用 `rose-500` 警示色。
3. **语音菜单状态机内聚**：原散在 ChatEntry 的 `openInputModeMenu`/`scheduleCloseInputModeMenu`/`handleInputModeMenuOpenChange` 收进 `VoiceMenuSendButton` 闭包，ChatEntry 少维护一份菜单状态、卸载清理由组件内 `clearCloseTimer` 自洽。
4. **主钮 onClick 不吞事件**：`handlePrimaryClick` 先 `e.stopPropagation()`（否则触发 `DropdownMenuTrigger` toggle 误开菜单），再关菜单、发送。
5. **三态分发顺序固定**：`loading && onStop` → 停止钮；`voiceMenu` 有无分流；都不命中走纯发送钮。顺序与原 ChatEntry 嵌套三元一致，勿调换。
