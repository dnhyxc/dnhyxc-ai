# 一、项目架构与技术栈

## 1.1 项目概述

**dnhyxc-ai** 是一个带知识库的 AI 助手应用，支持 Web 浏览器和 Tauri 桌面端双端运行。核心能力包括：智能对话、知识库 RAG、英语学习、电子书阅读、视频播放和动态插件扩展。

---

## 1.2 技术栈

### 前端技术栈

| 分类 | 技术选型 | 用途 |
|------|----------|------|
| **框架** | React 19 + TypeScript | 核心 UI 框架 |
| **构建** | Vite + Rspack | 开发构建、Module Federation |
| **状态管理** | MobX | 全局状态（chatStore、assistantStore 等） |
| **路由** | React Router v7 | SPA 路由管理 |
| **样式** | Tailwind CSS v4 + shadcn/ui | 原子化样式、组件库 |
| **Markdown** | Monaco Editor + MarkdownIt | 编辑器、预览 |
| **图表** | Mermaid | 流程图、时序图渲染 |
| **富文本** | Tiptap (ProseMirror) | 学习笔记编辑器 |
| **桌面壳** | Tauri 2.x | Rust + WebView 桌面打包 |
| **微前端** | Module Federation | 插件动态加载 |

### 后端技术栈

| 分类 | 技术选型 | 用途 |
|------|----------|------|
| **框架** | NestJS + TypeScript | API 服务、SSE 流式 |
| **ORM** | TypeORM | MySQL 数据访问 |
| **数据库** | MySQL 8.0 | 主数据存储 |
| **缓存** | Redis | 会话缓存、幂等锁 |
| **队列** | BullMQ | 异步消息落库 |
| **向量** | Qdrant | 向量存储与检索 |
| **LLM** | LangChain + ChatOpenAI | 大模型调用统一封装 |
| **对象存储** | 腾讯云 COS | 文件、头像、附件存储 |
| **支付** | Stripe | 会员充值 |

### 第三方服务

| 服务 | 用途 |
|------|------|
| 硅基流动 (SiliconFlow) | 大模型中转 |
| 智谱 AI (Zhipu) | 备选大模型、OCR |
| DashScope | Embedding 向量化、Rerank 重排 |
| Serper | 联网搜索 |
| MiniMax / 讯飞 | 云端 TTS 语音合成 |
| Edge TTS | 免费云端 TTS |

## 1.5 开发环境搭建

### 前置要求

- **Node.js** >= 18
- **pnpm** >= 8
- **Rust** >= 1.70（Tauri 构建）
- **MySQL** 8.0
- **Redis** >= 6.0
- **Qdrant** >= 1.6

### 快速开始

```bash
# 克隆项目
git clone <repo-url>
cd dnhyxc-ai

# 安装依赖
pnpm install

# 启动 MySQL 和 Redis
docker-compose up -d mysql redis qdrant

# 配置环境变量
cp apps/backend/.env.example apps/backend/.env
# 编辑 .env 填入 API Key 和连接串

# 启动后端
cd apps/backend
pnpm run start:dev

# 启动前端（另开终端）
cd apps/frontend
pnpm run dev

# Tauri 桌面端（另开终端）
cd apps/frontend
pnpm run tauri:dev
```

### 关键环境变量

```env
# 数据库
DB_HOST=localhost
DB_PORT=3306

DB_PASSWORD=xxx

# Redis

# JWT
JWT_SECRET=your-secret-key
JWT_EXPIRATION=7d
```

## 1.6 双端运行时差异

### 检测方法

```typescript
import { isTauriRuntime } from '@/utils/runtime';

if (isTauriRuntime()) {
  // Tauri 桌面端
  await invoke('select_files', { accept: '.epub,.pdf' });
} else {
  // Web 浏览器
  const input = document.createElement('input');
  input.type = 'file';
  input.click();
}
```

### 能力矩阵

| 能力 | Tauri 桌面端 | Web 浏览器 |
|------|-------------|-----------|
| 全局快捷键 | ✅ | ❌ |
| 本地文件选择 | ✅（原生对话框） | ⚠️（HTML input） |
| 本地目录扫描 | ✅ | ❌ |
| 系统托盘 | ✅ | ❌ |
| HTTP 重试 | ✅（所有方法） | ✅（GET/HEAD） |
| 剪贴板操作 | ✅（原生） | ⚠️（Web API） |
| 自动更新 | ✅ | ❌ |
| 开机自启 | ✅ | ❌ |
| 语音输入 | ✅ | ✅ |
| COS 直链 | ✅ | ⚠️（代理） |
