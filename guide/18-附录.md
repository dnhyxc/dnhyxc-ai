### 数据流（对话系统）

```
用户输入 "你好"
    │
    ▼
┌─────────────────────────────────────────┐
│  Frontend (React)                         │
│  1. Zustand store.message += user message │
│  2. SSE POST /chat/stream                │
│     Headers: Accept: text/event-stream   │
│     Body: { sessionId, content }         │
└──────────────────┬──────────────────────┘
                   │ HTTP/1.1 + SSE
                   ▼
┌─────────────────────────────────────────┐
│  Backend (NestJS)                        │
│  ChatController.stream()                 │
│  │                                       │
│  ├─ 解析 DTO (ValidationPipe)            │
│  ├─ 加载历史消息 (TypeORM)               │
│  ├─ [可选] 知识库检索 (Qdrant + RRF)     │
│  ├─ 调用 AgentService.decideTools()     │
│  ├─ [可选] SerperService.search()       │
│  ├─ 构建 Prompt (System + History + RAG) │
│  └─ LlmService.streamChat()             │
│     │                                    │
│     ▼ 调用 LLM API                       │
│  ┌─────────────────────────────────┐    │
│  │  Volcengine / MiniMax / ...      │    │
│  │  POST /api/v3/chat/completions  │    │
│  │  stream: true                    │    │
│  └──────────────┬──────────────────┘    │
│                 │ token 流              │
│                 ▼                        │
│  ServerSentEventGenerator.send()         │
│  → data: {"type":"token","data":"你"}\n\n │
│  → data: {"type":"token","data":"好"}\n\n │
│  → data: {"type":"done","data":null}\n\n │
└──────────────────┬──────────────────────┘
                   │ SSE Stream
                   ▼
┌─────────────────────────────────────────┐
│  Frontend (React)                         │
│  streamFetch() 解析 SSE:                  │
│  ├─ data: token → append to assistant msg │
│  ├─ data: done → isStreaming = false      │
│  └─ user sees: "你好"                     │
└─────────────────────────────────────────┘
```

  plugins: [

    federation({
      name: 'host',

        react: { singleton: true, requiredVersion: '^19.1.0' },
        'react-dom': { singleton: true, requiredVersion: '^19.1.0' },
        'react-router-dom': { singleton: true },
      },
    }),
  ],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),

  },
  server: {

      '/api': { target: 'http://localhost:3000', changeOrigin: true },

## 18.4 常用命令

### 开发

```bash
pnpm install                    # 安装依赖
pnpm start:web                  # 启动前端
pnpm start:server               # 启动后端
pnpm start:tauri                # 启动桌面端
pnpm start:all                  # 同时启动全部
```

### 构建

```bash
pnpm build:web                  # 构建前端
pnpm build:server               # 构建后端
pnpm build:tauri                # 构建桌面端
pnpm build                      # 全量构建
```

### 测试

```bash
pnpm test                       # 运行单元测试
pnpm test:watch                  # 监听模式
pnpm test:coverage              # 覆盖率
pnpm test:e2e                   # E2E 测试
```

### 代码质量

```bash
pnpm lint                       # ESLint 检查
pnpm format                     # Prettier 格式化
pnpm typecheck                  # TypeScript 类型检查
```

### 数据库

```bash
pnpm db:migrate                 # 运行迁移
pnpm db:migrate:create          # 创建迁移
pnpm db:seed                    # 种子数据
```

## 18.5 性能优化要点

| 领域 | 优化手段 |
|------|----------|
| 首屏 | 组件级 lazy loading、manualChunks、预加载关键路由 |
| SSE | 连接池复用、心跳保活、分片缓冲 |
| LLM | 流式输出、Prompt 缓存、Token 预算 |
| RAG | 向量预计算、BM25 缓存、TopK 裁剪 |
| EPUB | 懒加载章节、视口内渲染、Cfi 索引 |
| PDF | Canvas 分块渲染、Web Worker 解析 |
| TTS | 预生成音频、边下边播、缓存常用文本 |
| 网络 | HTTP/2、请求合并、增量同步 |
| 存储 | Redis 热数据、IndexedDB 离线、分层缓存 |

## 18.6 安全要点
