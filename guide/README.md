## 七、开发者上手手册（按功能域端到端）

本章节面向需要**理解 / 复用 / 改造**某一具体功能模块的开发者，按「白话原理 → 维护定位表 → M1–Mn 分阶段落地 → 运行时调用链 → 验收清单」组织成教程型手册，可在其他项目中按阶段照抄源码。

### 7.1 各文档类型定位与姊妹文档关系

| 文档类型 | 目录 | 适合谁看 | 内容粒度 |
| --- | --- | --- | --- |
| **专题实现文** | `docs/<功能域>/`（如 `docs/english/`） | 需要**改动**该功能的开发同学 | 改动前/改动后成对对比 + **100% 逐行中文注释**的源码摘录 + 完整符号边界 |
| **开发者上手手册** ← **本章** | `guide/` | 需要**理解 / 复用**该功能的开发同学 | 白话原理、维护定位表、分阶段落地（M1–Mn）、运行时调用链、按模块拆分、验收 checklist |
| **规划态思路文档** | `docs/ideas/` | 准备**新做 / 重构**某功能的设计阶段 | 架构图、流程图、模块职责、分阶段步骤 + 验收清单（默认不改业务源码） |
| **影响点分析** | `docs/impact/` | 回归阶段的 QA / 维护者 | 改动对既有需求的影响面矩阵、风险与回归清单 |
| **产品向说明** | `docs/项目指南.md`、`docs/项目更新信息.md` | 最终用户 / PM | 「怎么用」与「新增/优化了什么」，**正文不出现路径或代码文件名** |
| **全流程开发手册** ← **本手册第一至第六章** | `guide/`（01–18 章节） | 需要**系统学习**整个项目的开发者 | 宏观架构、技术选型、目录结构、各业务模块概述（按 01–18 章节系统阅读） |
