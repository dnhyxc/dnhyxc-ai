# 三、样式隔离

## 3.1 技术总览

### 3.1.1 方案选择

本系统采用 **CSS `@scope` + qiankun 式转译 + DOM/CSSOM 劫持 + MutationObserver + Portal/Teleport 收编** 的组合方案，实现零侵入的主子项目样式隔离。

### 3.1.2 技术对比

| 方案 | 改造成本 | 隔离效果 | 性能 | 主题继承 | 本项目采用 |
|------|---------|---------|------|---------|-----------|
| **CSS @scope + 劫持** | 零侵入 | 良好 | 高 | ✅ | ✅ |
| Shadow DOM | 中 | 完全 | 中 | ❌ | ❌ |
| CSS Modules | 中 | 较好 | 高 | ✅ | ❌ |
| qiankun strictStyleIsolation | 低 | 完全 | 中 | ❌ | ❌ |
| iframe | 低 | 完全 | 低 | ❌ | ✅（untrusted） |

### 3.1.3 核心特性

- ✅ **零侵入**：子项目按普通项目开发即可，无需特殊改造
- ✅ **性能优异**：基于浏览器原生 `@scope`，无运行时选择器改写开销
- ✅ **主题统一**：子项目自动继承宿主 CSS 变量
- ✅ **事件正常**：React 事件系统不受影响
- ✅ **覆盖全面**：同步/异步/HMR 注入的样式都能正确捕获

## 3.2 CSS @scope 原生规则

### 3.2.1 基本用法

`@scope` 是 CSS 原生作用域规则（Chrome 118+ / Firefox 125+ / Safari 17.4+）：

```css
/* 只有在 [data-mf-plugin="my-plugin"] 容器内生效 */
@scope ([data-mf-plugin="my-plugin"]) {
  .button { background: blue; }
  body { margin: 0; }
  .container {
    /* 嵌套 @scope 合法 */
    @scope (.inner) {
      .deep { color: red; }
    }
  }
}
```

### 3.2.2 关键特性

- 选择器不会"漏出"容器外
- 支持 Tailwind、CSS 变量、`@keyframes` 等所有 CSS 特性
- 可以继承容器外的 CSS 变量（主题统一的基础）
- 原生性能，无运行时开销

### 3.2.3 浏览器支持

```typescript
const isScopeSupported = CSS.supports?.('@scope', '(.foo) {}') ?? false;
// Chrome: 118+ ✅
// Firefox: 125+ ✅
// Safari: 17.4+ ✅
```

## 3.3 实现流程

### 3.3.1 两阶段捕获

| 阶段 | 触发时机 | 捕获内容 | 持续时间 |
|------|---------|---------|---------|
| **初始加载捕获** | `loadRemoteApp` 前后 | 插件入口及依赖模块的 CSS | 加载完成即结束 |
| **运行时持续捕获** | `PluginHostPage` 挂载期间 | HMR 热更新、动态 `import()`、第三方库注入 | 组件整个生命周期 |

### 3.3.2 完整流程

```
1. PluginManager.runLoad(meta)
   │
   ├─ beginPluginStyleCapture(pluginId, entry)
   │   │
   │   ├─ 保存当前 active 上下文
   │   ├─ ensureHeadPatch()              // 劫持 head.appendChild/insertBefore
   │   │   ├─ 保存原生方法引用
   │   │   ├─ patchDepth = 1
   │   │   └─ 重写方法 → 调用后 processNode()
   │   │
   │   ├─ 创建 MutationObserver
   │   │   └─ 监听 head childList/subtree/characterData
   │   │
   │   └─ 返回 endCapture 清理函数
   │
   ├─ loadRemoteApp(meta)               // MF 加载
   │   │                                // 此过程中样式被注入 head
   │   │   ├─ style 标签 → processNode → scopeStyleElement()
   │   │   │   ├─ 检查 looksLikeRemoteStyle() 归属

   │   │   │   └─ 标记 data-mf-scoped="1"
   │   │   │

   │   │   │   ├─ fetch CSS 内容
   │   │   │   ├─ wrapWithScope(text, selector)
   │   │   │   ├─ 创建 scoped style 标签
   │   │   │   └─ 禁用原 link
   │   │   │
   │   │   └─ CSS-in-JS → insertRule 劫持 → transpileStyleRule()
   │   │
   ├─ endCapture()                       // 结束初始捕获
   │
   └─ PluginHostPage 渲染

           └─ 插件组件卸载时自动清理
```

### 3.3.3 样式识别策略

```typescript
function looksLikeRemoteStyle(
  el: HTMLStyleElement | HTMLLinkElement,
  ctx: CaptureCtx,
): boolean {
  // 1. 已标记元素：检查 data-mf-style-owner 属性
  if (el.dataset.mfStyleOwner) {
    return el.dataset.mfStyleOwner === ctx.pluginId;
  }

  // 2. link 标签：比对 href origin 与插件入口 origin
  if (el instanceof HTMLLinkElement) {
    if (el.rel !== 'stylesheet' || !el.href) return false;
    return new URL(el.href).origin === ctx.entryOrigin;
  }

  // 3. style 标签：Vite 开发模式检查 data-vite-dev-id
  const viteId = el.getAttribute('data-vite-dev-id') || '';
  if (viteId) {
    return isRemoteViteDevStyle(viteId, ctx);
  }

  // 4. 生产环境：捕获窗口期内注入的归属于当前插件
  return active?.pluginId === ctx.pluginId;
}
```

## 3.4 核心实现代码

### 3.4.1 styleIsolation.ts

```typescript
// 捕获上下文
type CaptureCtx = {
  pluginId: string;
  entryOrigin: string;
};

let active: CaptureCtx | null = null;
let patchDepth = 0;
let origAppend: typeof document.head.appendChild;
let origInsert: typeof document.head.insertBefore;

// CSS 标识符转义
function cssEscapeIdent(id: string): string {
  if (typeof CSS !== 'undefined' && CSS.escape) return CSS.escape(id);
  return id.replace(/[^a-zA-Z0-9_-]/g, '\\$&');
}

// 生成 @scope 选择器
function scopeSelector(pluginId: string): string {
  return `[data-mf-plugin="${cssEscapeIdent(pluginId)}"]`;
}

// 检测是否已被 @scope 包裹
function alreadyScoped(text: string, sel: string): boolean {
  return text.includes(`@scope (${sel})`) || text.includes(`@scope(${sel})`);
}

// 用 @scope 包裹 CSS
function wrapWithScope(cssText: string, sel: string): string {
  const trimmed = cssText.trim();
  if (!trimmed || alreadyScoped(trimmed, sel)) return cssText;
  return `@scope (${sel}) {\n${trimmed}\n}\n`;
}

// 处理 style 标签
function scopeStyleElement(el: HTMLStyleElement, pluginId: string) {
  if (el.dataset.mfScoped === '1') return;
  const sel = scopeSelector(pluginId);
  const text = el.textContent ?? '';

  // Vite 空 style → 监听内容变化
  if (!text.trim()) {
    const mo = new MutationObserver(() => {
      if ((el.textContent ?? '').trim()) {
        mo.disconnect();
        scopeStyleElement(el, pluginId);
      }
    });
    mo.observe(el, { childList: true, characterData: true, subtree: true });
    return;
  }

  el.textContent = wrapWithScope(text, sel);
  el.dataset.mfScoped = '1';
  el.dataset.mfStyleOwner = pluginId;
}

// 处理 link 标签
async function scopeLinkElement(el: HTMLLinkElement, pluginId: string) {
  if (el.dataset.mfScoped === '1') return;
  const href = el.href;
  if (!href) return;

  try {
    const res = await fetch(href, { credentials: 'omit', mode: 'cors' });
    if (!res.ok) return;
    const css = await res.text();

    const style = document.createElement('style');
    style.textContent = wrapWithScope(css, scopeSelector(pluginId));
    style.dataset.mfScoped = '1';
    style.dataset.mfStyleOwner = pluginId;
    el.insertAdjacentElement('afterend', style);

    el.dataset.mfScoped = '1';
    el.disabled = true;
  } catch {
    // CORS/离线：优雅降级
  }
}

// 劫持 DOM 方法
function ensureHeadPatch() {
  if (patchDepth > 0) { patchDepth++; return; }

  origAppend = document.head.appendChild.bind(document.head);
  origInsert = document.head.insertBefore.bind(document.head);

  document.head.appendChild = function appendScoped<T extends Node>(node: T): T {
    const ret = origAppend(node);
    if (active) processNode(node, active);
    return ret;
  };

  document.head.insertBefore = function insertScoped<T extends Node>(node: T, ref: Node | null): T {
    const ret = origInsert(node, ref);
    if (active) processNode(node, active);
    return ret;
  };

  patchDepth = 1;
}

function releaseHeadPatch() {
  if (patchDepth <= 0) return;
  patchDepth--;
  if (patchDepth > 0) return;
  document.head.appendChild = origAppend;
  document.head.insertBefore = origInsert;
}

// 对外 API：开始样式捕获
export function beginPluginStyleCapture(pluginId: string, entry: string): () => void {
  const ctx: CaptureCtx = { pluginId, entryOrigin: new URL(entry).origin };
  const prev = active;
  active = ctx;
  ensureHeadPatch();

  const obs = new MutationObserver((mutations) => {
    if (!active || active.pluginId !== pluginId) return;
    for (const m of mutations) {
      for (const n of m.addedNodes) processNode(n, ctx);
      if (m.type === 'childList' && m.target instanceof HTMLStyleElement) {
        if (looksLikeRemoteStyle(m.target, ctx)) {
          scopeStyleElement(m.target, pluginId);
        }
      }
    }
  });
  obs.observe(document.head, { childList: true, subtree: true, characterData: true });

  return () => {
    obs.disconnect();
    if (active?.pluginId === pluginId) active = prev;
    releaseHeadPatch();
  };
}

// 对外 API：运行时持续隔离
export function attachPluginStyleIsolation(pluginId: string, entry: string): () => void {
  return beginPluginStyleCapture(pluginId, entry);
}
```

```typescript
// PluginManager.ts - runLoad 方法
private async runLoad(meta: PluginDescriptor) {
  // ... 前置逻辑

  // untrusted 插件走 iframe，不需要 JS 侧隔离
  if (meta.trust === 'untrusted') {
    // ...
    return;
  }

  registerRemote(meta);

  // ★ 关键：在加载前开启样式捕获
  const endCapture = beginPluginStyleCapture(meta.id, meta.entry);
  let mod: Awaited<ReturnType<typeof loadRemoteApp>>;

  try {
    mod = await loadRemoteApp(meta);
  } finally {
    // ★ 关键：无论成功失败都结束捕获
    endCapture();
  }

  // ... 后续逻辑
}
```

### 3.4.3 PluginHostPage 集成

```typescript
// PluginHostPage.tsx
export function PluginHostPage({ pluginId }: Props) {
  const loaded = pluginManager.get(pluginId);
  const entry = loaded?.meta.entry;
  const trust = loaded?.meta.trust;
  const status = loaded?.status;

  // ★ 关键：运行时持续样式隔离
  useEffect(() => {
    if (status !== 'activated' || trust === 'untrusted' || !entry) return;
    return attachPluginStyleIsolation(pluginId, entry);
  }, [pluginId, status, entry, trust]);

  if (loaded?.status === 'activated') {
    // trusted 模式：MF 加载 + @scope 隔离
    if (loaded.meta.trust !== 'untrusted') {
      const Comp = loaded.mod.default;
      return (
        <PluginErrorBoundary pluginId={pluginId}>
          <div
            className={`plugin-${pluginId} h-full w-full`}
            data-mf-plugin={pluginId}
            data-plugin-root
          >
            <Comp {...loaded.bridge} />
          </div>
        </PluginErrorBoundary>
      );
    }

    // untrusted 模式：iframe 隔离
    return (
      <PluginErrorBoundary pluginId={pluginId}>
        <UntrustedIframe
          pluginId={pluginId}
          src={loaded.meta.iframeUrl}
          bridge={loaded.bridge}
        />
      </PluginErrorBoundary>
    );
  }
}
```

## 3.5 qiankun 式加固（进阶）

### 3.5.1 transpileStyleText

处理 `@font-face` hoist、`@keyframes` realm 前缀等复杂场景：

```typescript
// styleIsolationQiankun.ts
export function transpileStyleText(cssText: string, realmSelector: string): string {
  const parts: string[] = [];
  let buffer = '';
  let inFontFace = false;
  let inKeyframes = false;

  // 解析 CSS，分离全局 at-rule 和普通规则
  for (let i = 0; i < cssText.length; i++) {
    if (cssText[i] === '@' && cssText.slice(i, i + 10) === '@font-face') {
      if (buffer) { parts.push(wrapWithScope(buffer, realmSelector)); buffer = ''; }
      inFontFace = true;
    }
    if (cssText[i] === '@' && cssText.slice(i, i + 10) === '@keyframes') {
      if (buffer) { parts.push(wrapWithScope(buffer, realmSelector)); buffer = ''; }
      inKeyframes = true;
    }
    // ... 括号匹配逻辑
  }

  return parts.join('\n');
}
```

### 3.5.2 CSSOM 劫持

```typescript
// 劫持 StyleSheet.insertRule，捕获 CSS-in-JS 注入
function hijackCSSOM() {
  const origInsertRule = CSSStyleSheet.prototype.insertRule;

  CSSStyleSheet.prototype.insertRule = function(rule: string, index?: number) {
    if (active) {
      rule = transpileStyleRule(rule, scopeSelector(active.pluginId));
    }
    return origInsertRule.call(this, rule, index);
  };

  return () => {
    CSSStyleSheet.prototype.insertRule = origInsertRule;
  };
}
```

### 3.5.3 Portal/Teleport 收编

```typescript
// 劫持 React Portal，将 body 挂载收编到插件容器
function hijackPortal() {
  const origCreatePortal = ReactDOM.createPortal;

  ReactDOM.createPortal = function(children: ReactNode, container: Element, key?: string) {
    // 检查 container 是否在插件容器内
    const pluginRoot = document.querySelector('[data-mf-plugin]');
    if (pluginRoot && !pluginRoot.contains(container)) {
      // 将 body 上的 Portal 收编到插件容器
      const scopedContainer = pluginRoot.querySelector('[data-plugin-root]') || pluginRoot;
      return origCreatePortal(children, scopedContainer as Element, key);
    }
    return origCreatePortal(children, container, key);
  };
}
```

## 3.6 子项目开发规范

### 3.6.1 零侵入开发

子项目可以像普通前端项目一样开发：

- ✅ 正常使用 `@import "tailwindcss"`
- ✅ 正常写全局样式（`body`、`html`、`#root` 等）
- ✅ 正常使用 CSS Modules / CSS-in-JS
- ✅ 正常使用第三方组件库（shadcn/ui、Ant Design 等）
- ✅ 正常使用 CSS 变量、`@keyframes`
- ✅ 正常配置 Vite / Webpack

### 3.6.2 唯一注意点

**外链 CSS CORS 配置**：如果使用 `<link rel="stylesheet">` 引入跨域 CSS：

```nginx
location /static/css/ {
  add_header Access-Control-Allow-Origin *;
}
```

建议：尽量将 CSS 打包进 JS 中（Vite 默认行为），避免 CORS 问题。

### 3.6.3 主题继承

子项目自动继承宿主的 CSS 变量：

```css
/* 子项目可以直接使用宿主的主题变量 */
.my-component {
  background: var(--background);
  color: var(--foreground);
  border: 1px solid var(--border);
}

/* :root 选择器只会在插件容器内生效 */
:root {
  --my-plugin-color: blue;
}
```

## 3.7 常见问题

### Q1：子项目的 Tailwind 会和宿主冲突吗？
不会。所有 Tailwind 类名都会被 `@scope` 包裹，只在插件容器内生效。

### Q2：子项目写 `body { margin: 0 }` 会影响宿主吗？
不会。被 `@scope` 包裹后，选择器只在插件容器内匹配。

### Q3：HMR 热更新时样式会闪烁吗？
不会。插件页面挂载期间持续捕获样式，HMR 注入的新 style 会被立即 scoped 处理。

### Q4：浏览器不支持 @scope 会怎样？
`@scope` 规则会被浏览器忽略，样式变成全局的，功能不受影响，只是隔离失效。

### Q5：untrusted 插件的样式隔离也是这个方案吗？
不是。untrusted 插件使用 iframe 加载，天然完全隔离（独立 document），不需要 @scope 方案。
