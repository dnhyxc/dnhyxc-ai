# 十六、开发环境与工作流

## 16.1 环境搭建

### 16.1.1 前置依赖

| 依赖 | 版本 | 说明 |
|------|------|------|
| Node.js | >= 18.0 | 推荐 LTS |
| pnpm | >= 8.0 | 包管理器 |
| PostgreSQL | >= 14 | 关系数据库 |
| Redis | >= 6.0 | 缓存 |
| Qdrant | >= 1.7 | 向量数据库 |
| Tauri | >= 1.5 | 桌面框架（可选） |
| Rust | >= 1.70 | Tauri 编译（可选） |

### 16.1.2 快速开始

```bash
# 克隆仓库
git clone <repo-url>
cd dnhyxc-ai

# 安装依赖
pnpm install

# 配置环境变量
cp .env.example .env
# 编辑 .env 填写 API Key

# 启动数据库
docker compose up -d postgres redis qdrant

# 运行后端
pnpm start:server

# 运行前端
pnpm start:web

# 运行桌面端（可选）
pnpm start:tauri
```

describe('EmbeddingService', () => {

    const batches = mockFetch.mock.calls.length;

    await service.embedChunks(chunks);

### 16.4.3 集成测试

```typescript
// tests/integration/knowledge.e2e.ts
describe('Knowledge Document Flow', () => {
  it('should create document and index it', async () => {
    // 1. 创建文档
    const createRes = await request(app)
      .post('/knowledge/documents')
      .send({ title: 'Test', content: '# Hello World', type: 'markdown' })
      .set('Authorization', `Bearer ${token}`);

    expect(createRes.status).toBe(201);
    expect(createRes.body.isIndexed).toBe(false);

    // 2. 触发索引
    const indexRes = await request(app)
      .post(`/knowledge/documents/${createRes.body.id}/index`)
      .set('Authorization', `Bearer ${token}`);

    expect(indexRes.status).toBe(200);

    // 3. 验证索引状态
    const docRes = await request(app)
      .get(`/knowledge/documents/${createRes.body.id}`)
      .set('Authorization', `Bearer ${token}`);

    expect(docRes.body.isIndexed).toBe(true);
  });
});
```

## 16.6 CI/CD

### 16.6.1 GitHub Actions

```yaml
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]

jobs:
  lint-and-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: pnpm/action-setup@v3
        with:
          version: 8

      - uses: actions/setup-node@v4
        with:
          node-version: 20

      - run: pnpm install --frozen-lockfile

      - run: pnpm lint

      - run: pnpm typecheck

      - run: pnpm test

  build:
    needs: lint-and-test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: pnpm install
      - run: pnpm build:web
      - run: pnpm build:server

      - uses: actions/upload-artifact@v4
        with:
          name: dist
          path: |
            web/dist
            server/dist
```

### 16.6.2 部署流水线

```yaml
# .github/workflows/deploy.yml
name: Deploy

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    environment: production
    steps:
      - uses: actions/checkout@v4

      - name: Deploy to server
        uses: appleboy/ssh-action@v1
        with:
          host: ${{ secrets.DEPLOY_HOST }}
          username: ${{ secrets.DEPLOY_USER }}
          key: ${{ secrets.DEPLOY_KEY }}
          script: |
            cd /app/dnhyxc-ai
            git pull
            pnpm install --production
            pnpm build:server
            pm2 restart dnhyxc-ai
```

### 16.7.2 SSE 调试

```typescript
// 开发环境 SSE 日志
if (import.meta.env.DEV) {
  const originalFetch = window.fetch;
  window.fetch = async (...args) => {
    const response = await originalFetch(...args);
    const url = typeof args[0] === 'string' ? args[0] : args[0].url;

    if (url.includes('/stream')) {
      console.log('[SSE] Request:', url);
      console.log('[SSE] Status:', response.status);

      // 克隆响应以同时记录和消费
      const clone = response.clone();
      const reader = clone.body!.getReader();
      const decoder = new TextDecoder();
      let buffer = '';

      reader.read().then(function processChunk() {
        const { done, value } = reader.read();
        if (done) return;
        buffer += decoder.decode(value);
        console.log('[SSE] Chunk:', buffer);
        processChunk();
      });
    }

    return response;
  };
}
```
