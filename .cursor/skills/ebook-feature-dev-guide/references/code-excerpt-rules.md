# 开发者手册 — 源码摘录与逐行注释规则

适用于 `docs/ebook/developer/*.md` 围栏代码块。与 `implementation-doc-from-diff` 的差异：**不要求改动前/改动后**；摘录**当前仓库实现**作为参考。

## 1. 摘录范围（完整符号）

- 从**符号声明行**写到**闭合**（函数 `}`、`useCallback`/`useMemo` 的 `}, [deps]);`、组件函数闭合）。
- **禁止**只贴函数体或孤立 `return { … }` 而无外层 hook/函数定义。
- 小节标题中的符号名须在代码块内**可见**。
- 大段未改上下文可用 `// ...（未改动）` 省略，**省略行上一行**须说明省略范围；**不得**省略声明行或 hook 闭合。

细则与反例见 `implementation-doc-from-diff/references/code-symbol-scope.md`（符号边界部分）。

## 2. 逐行上方详细注释（100%）

- 围栏块内**每一行源码**正上一行一行**详细**中文注释。
- 注释写**运行时语义**（做了什么、为什么、与上下游关系），禁止语法标签式注水（「条件分支」「闭合括号」）。
- 保留源码已有行内/块注释；讲解注释作为**上方额外行**追加。
- **禁止** `讲解：`、`说明：`、`注：` 前缀。
- **JSX/HTML 标记节点行**可豁免（`<Tag>`、`</Tag>`、纯属性行）；`import`、逻辑、`return (` 前的 TS 仍须注释。
- `return` 对象每个属性行、`onXxx` 回调属性及回调体内每一行、`useMemo` deps 每个元素行**均须**注释。

语义质量与 §1.3 细则见 `code-line-comments` skill 与 `implementation-doc-from-diff/references/code-line-comments.md`。

## 3. 来源标注（每个围栏块必做）

紧挨 ``` 之前写：

```markdown
**来源**：`apps/frontend/src/.../foo.ts` · 约 L42–L58
```

- 路径：仓库根相对路径。
- 行号：对应当前源码；不便给行号时写符号名 + 一句方位。

## 4. 摘录后 prose

每个符号块末尾加 **「读完应掌握」** 1～3 句：该符号在整条链路中的职责、调用方、失败时表现。

## 5. 落盘前扫描

1. 块内每行源码（除 JSX 豁免）上一行是否为有信息增益的中文注释。
2. 符号是否完整（声明 → 闭合）。
3. 是否与仓库当前文件一致；不一致则在文末保留「以源码为准」声明。

## 6. 禁止

- 臆造仓库中不存在的 API、文件、符号。
- 粘贴机密（密钥、内网 URL）。
- 把整文件无差别粘贴；只摘录**理解该功能所必需**的符号，按链路优先级排序。
